图1：请求生命周期

请求从进入应用到返回响应的完整路径

graph TD
    REQ["📩 HTTP 请求"] --> MID["🔄 Middleware\n中间件"]
    MID --> GUA["🛡️ Guard\n守卫"]
    GUA --> INT1["🔧 Interceptor\n拦截器（前置）"]
    INT1 --> PIP["🔍 Pipe\n管道"]
    PIP --> CTR["🎮 Controller\n控制器"]
    CTR --> SRV["⚙️ Service\n服务层"]
    SRV --> DB[("🗄️ Database\n数据库")]
    DB --> SRV
    SRV --> CTR
    CTR --> INT2["🔧 Interceptor\n拦截器（后置）"]
    INT2 --> FLT{"❌ 异常？"}
    FLT -->|"是"| EXC["⚠️ ExceptionFilter\n异常过滤器"]
    FLT -->|"否"| RES["📨 HTTP 响应"]
    EXC --> RES
